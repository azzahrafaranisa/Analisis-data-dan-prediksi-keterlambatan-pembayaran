# Analisis Data dan Prediksi Keterlambatan Pembayaran

## Deskripsi
Studi kasus PT Maju Bersama untuk menerapkan analisis data dan
machine learning dalam memahami data bisnis serta memprediksi
keterlambatan pembayaran.

## Tujuan
- Menganalisis data penjualan dan keuntungan.
- Mengidentifikasi pola keterlambatan pembayaran.
- Membangun model Random Forest untuk prediksi keterlambatan pembayaran.
- Menyajikan hasil analisis sebagai dasar pengambilan keputusan.

## Metode
1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Descriptive Analytics
5. Predictive Analytics menggunakan Random Forest
6. Evaluasi model dan rekomendasi bisnis

## Teknologi
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Cara Menjalankan
1. Pastikan Python sudah terpasang.
2. Instal library yang diperlukan:

   ```bash
   pip install -r requirements.txt
   ```

3. Jalankan program:

   ```bash
   python main.py
   ```

## Catatan
Data yang digunakan merupakan data simulasi untuk keperluan studi kasus.
